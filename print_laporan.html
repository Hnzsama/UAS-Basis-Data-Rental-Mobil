BAB I
PENDAHULUAN

1.1 Latar Belakang Pemilihan Topik

Perkembangan teknologi informasi saat ini menuntut efisiensi operasional di berbagai sektor bisnis, tidak terkecuali bidang jasa transportasi seperti persewaan kendaraan. Sistem manual yang mengandalkan pencatatan kertas rawan terhadap kesalahan input data, kehilangan dokumen, dan kesulitan dalam monitoring armada secara langsung. Oleh karena itu, dirancang "Sistem Informasi Rental Mobil" untuk mempermudah manajemen operasional, mulai dari integrasi data identitas pelanggan, monitoring status unit mobil, transaksi sewa, hingga pencatatan transaksi pengembalian dan kalkulasi denda.

1.2 Proses Bisnis dan Modul Sistem

Sistem Informasi Rental Mobil ini diuraikan ke dalam empat modul fungsional utama:

  1. Modul Pelanggan (Keanggotaan): Mengelola proses registrasi pelanggan baru dengan menginput detail data pribadi seperti Nama, Nomor KTP, Nomor Telepon, dan Alamat ke dalam tabel master pelanggan.
  2. Modul Mobil (Armada): Mengelola data armada mobil rental. Operator dapat memasukkan spesifikasi unit (Merek, Tipe/Model, Nomor Plat Polisi, Tarif Harian) serta memperbarui status ketersediaan unit.
  3. Modul Transaksi Sewa: Mencatat pemesanan penyewaan unit oleh pelanggan. Sistem akan mencatat tanggal mulai sewa, batas jatuh tempo rencana kembali, serta menghitung estimasi tarif sementara. Selama transaksi aktif, status armada dirubah menjadi 'Disewa'.
  4. Modul Pengembalian & Denda: Mencatat penyelesaian sewa ketika mobil dikembalikan. Sistem mencatat tanggal aktual kembali dan secara otomatis menghitung tarif denda keterlambatan jika melewati masa jatuh tempo rencana awal.

1.3 Pihak yang Terlibat (Aktor)

Peran pengguna yang terlibat di dalam operasional sistem ini adalah:

  1. Pelanggan (Customer): Berperan sebagai penyewa unit mobil yang menyepakati durasi rental, menerima tagihan, dan bertanggung jawab mengembalikan mobil tepat waktu serta membayar denda apabila melakukan pelanggaran batas jatuh tempo.
  2. Admin / Operator Rental: Berperan sebagai pengelola data transaksi sewa-menyewa, memvalidasi data identitas pelanggan, melakukan update berkala ketersediaan unit mobil, serta mencatat transaksi pengembalian pelanggan.

2.2 Deskripsi Entitas dan Atribut

  • Pelanggan: Entitas master penyewa. Atribut kunci utama adalah id_pelanggan, atribut pelengkap terdiri dari nama, no_ktp (unik), no_telp, dan alamat.
  • Mobil: Entitas master kendaraan. Atribut kunci utama adalah id_mobil, atribut pelengkap terdiri dari merek, model, plat_nomor (unik), harga_sewa_perhari, dan status.
  • Transaksi Sewa: Entitas transaksi utama. Atribut kunci utama adalah id_sewa, terhubung ke pelanggan (id_pelanggan) dan mobil (id_mobil) sebagai Foreign Key. Atribut lainnya adalah tgl_sewa, tgl_kembali_rencana, dan total_bayar.
  • Pengembalian: Entitas transaksi detail penyelesaian sewa. Atribut kunci utama adalah id_kembali, terhubung ke id_sewa sebagai Foreign Key unik (1:1). Atribut lainnya adalah tgl_kembali_aktual dan denda.

2.3 Analisis Hubungan Kardinalitas

  1. Pelanggan ke Transaksi Sewa (1 : N / One-to-Many): Satu pelanggan dapat menyewa kendaraan berkali-kali secara berkala. Namun, setiap satu nota transaksi penyewaan hanya dapat dirujuk ke satu pelanggan saja.
  2. Mobil ke Transaksi Sewa (1 : N / One-to-Many): Satu unit mobil dapat disewakan kembali pada banyak nota transaksi yang berbeda di masa mendatang. Namun, satu nota sewa hanya berlaku untuk satu unit mobil tertentu.
  3. Transaksi Sewa ke Pengembalian (1 : 1 / One-to-One): Satu nota transaksi sewa hanya memiliki satu data pengembalian sebagai validasi penyelesaian sewa.

BAB IV
IMPLEMENTASI DATABASE (SQL SCRIPT - DDL)

4.1 Script DDL (Data Definition Language)

Berikut adalah DDL SQL untuk mendefinisikan database dan seluruh tabel berserta relasi foreign key:

CREATE DATABASE uas_rental_mobil;
USE uas_rental_mobil;

-- Membuat Tabel Pelanggan
CREATE TABLE pelanggan (
    id_pelanggan INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(100) NOT NULL,
    no_ktp VARCHAR(16) NOT NULL UNIQUE,
    no_telp VARCHAR(15) NOT NULL,
    alamat TEXT NOT NULL
);

-- Membuat Tabel Mobil
CREATE TABLE mobil (
    id_mobil INT AUTO_INCREMENT PRIMARY KEY,
    merek VARCHAR(50) NOT NULL,
    model VARCHAR(50) NOT NULL,
    plat_nomor VARCHAR(15) NOT NULL UNIQUE,
    harga_sewa_perhari INT NOT NULL,
    status VARCHAR(20) DEFAULT 'Tersedia'
);

-- Membuat Tabel Transaksi Sewa
CREATE TABLE transaksi_sewa (
    id_sewa INT AUTO_INCREMENT PRIMARY KEY,
    id_pelanggan INT NOT NULL,
    id_mobil INT NOT NULL,
    tgl_sewa DATE NOT NULL,
    tgl_kembali_rencana DATE NOT NULL,
    total_bayar INT NOT NULL,
    FOREIGN KEY (id_pelanggan) REFERENCES pelanggan(id_pelanggan) ON DELETE CASCADE,
    FOREIGN KEY (id_mobil) REFERENCES mobil(id_mobil) ON DELETE CASCADE
);

-- Membuat Tabel Pengembalian
CREATE TABLE pengembalian (
    id_kembali INT AUTO_INCREMENT PRIMARY KEY,
    id_sewa INT NOT NULL UNIQUE,
    tgl_kembali_aktual DATE NOT NULL,
    denda INT DEFAULT 0,
    FOREIGN KEY (id_sewa) REFERENCES transaksi_sewa(id_sewa) ON DELETE CASCADE
);

BAB V
IMPLEMENTASI APLIKASI CRUD

5.1 Program CRUD Python (CLI/Console)

Aplikasi berbasis teks (CLI) interaktif di terminal dengan query parameter untuk keamanan kueri:

import mysql.connector

def connect_db():
    return mysql.connector.connect(
        host="localhost", user="root", password="", database="uas_rental_mobil"
    )

def create_mobil(merek, model, plat, harga):
    db = connect_db()
    cursor = db.cursor()
    sql = "INSERT INTO mobil (merek, model, plat_nomor, harga_sewa_perhari) VALUES (%s, %s, %s, %s)"
    cursor.execute(sql, (merek, model, plat, harga))
    db.commit()
    db.close()

5.2 Program CRUD PHP (Web MVC App)

Aplikasi berbasis web menggunakan arsitektur modular MVC (Model-View-Controller) dengan prepared statements:

  • Model (Mobil.php): Mengelola query data (INSERT, SELECT, UPDATE, DELETE) dengan parameter binding (bind_param) untuk menangkal celah SQLi.
  • View (mobil_view.php): Halaman antarmuka yang bersih berbasis responsif web framework Tailwind CSS v4.
  • Controller (MobilController.php): Mengarahkan pergerakan logika data serta validasi request dari client.
