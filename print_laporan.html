UAS Basis Data

Laporan Perancangan Basis Data & Aplikasi CRUD Rental Mobil

1. Topik yang Dipilih

Topik: b. Sistem Informasi Rental Mobil

Sistem ini dirancang untuk mengelola seluruh alur operasional bisnis rental mobil, mulai dari pendaftaran data pelanggan, inventarisasi status armada mobil, pengelolaan transaksi peminjaman (sewa), hingga pencatatan aktualisasi pengembalian mobil beserta perhitungan nominal denda keterlambatan secara otomatis.

2. Proses Bisnis dan Modul

A. Modul Pelanggan (Keanggotaan)

Setiap pelanggan baru wajib melakukan registrasi dengan menyertakan informasi identitas penting, antara lain nama lengkap, nomor induk KTP, nomor kontak aktif, dan alamat domisili. Admin akan memasukkan data ini ke sistem sebagai data master pelanggan.

B. Modul Mobil (Armada)

Mencakup inventarisasi seluruh unit mobil milik rental. Operator menginput data spesifikasi mobil (merek, model, nomor plat polisi, harga sewa per hari) dan memantau ketersediaan armada secara real-time melalui kolom status.

C. Modul Transaksi Sewa

Saat pelanggan melakukan pemesanan, sistem akan membuat catatan penyewaan baru. Pelanggan memilih mobil berstatus 'Tersedia' dan menentukan durasi sewa. Sistem menghitung perkiraan total bayar sementara, lalu mengubah status mobil menjadi 'Disewa' agar tidak terjadi double-booking.

D. Modul Pengembalian & Denda

Saat masa sewa selesai, mobil dikembalikan dan dicatat tanggal aktual kembalinya. Jika tanggal kembali melebihi batas jatuh tempo (rencana kembali), sistem secara dinamis mengalkulasikan denda keterlambatan. Setelah transaksi dinyatakan lunas, status mobil dikembalikan menjadi 'Tersedia'.

3. Pihak yang Terlibat (Aktor)

  1. Pelanggan (Customer): Pihak luar yang menyewa kendaraan, berkewajiban menyerahkan berkas data pribadi, mematuhi batas sewa, dan membayar biaya serta denda.
  2. Admin / Operator Rental: Pengguna internal sistem yang bertanggung jawab melakukan input data pelanggan, memperbarui status unit mobil, membuat nota transaksi sewa, dan memproses penyerahan kembali mobil serta denda.

5. Kardinalitas Hubungan Antar Entitas

A. Pelanggan ke Transaksi Sewa (1 : N / One-to-Many)

Kardinalitas: 1 Pelanggan dapat melakukan banyak (N) Transaksi Sewa. Satu transaksi sewa hanya dimiliki oleh tepat 1 pelanggan terdaftar.

B. Mobil ke Transaksi Sewa (1 : N / One-to-Many)

Kardinalitas: 1 Mobil dapat disewakan dalam banyak (N) Transaksi Sewa seiring waktu secara bergantian. Satu transaksi sewa hanya melibatkan 1 unit mobil.

C. Transaksi Sewa ke Pengembalian (1 : 1 / One-to-One)

Kardinalitas: 1 Transaksi Sewa memiliki maksimal 1 data Pengembalian (kondisi opsional, 1-to-0-or-1 ketika transaksi masih aktif). Setiap catatan pengembalian hanya merujuk ke 1 transaksi sewa.

6. Normalisasi Database

Proses dekomposisi tabel dilakukan untuk menghilangkan redundansi dan mengamankan integritas data terhadap anomali transaksi.

A. Bentuk Tidak Ternormalisasi (UNF) & 1NF (First Normal Form)

Semua kolom dikelompokkan ke satu baris data atomic tanpa repeating groups:

Nama Kolom Jenis Kunci Keterangan
id_sewaPrimary Key (PK)ID unik transaksi sewa
id_pelanggan-ID Pelanggan
nama_pelanggan-Nama lengkap pelanggan
no_ktp-Nomor KTP pelanggan
id_mobil-ID Mobil
merek_mobil-Merek mobil
plat_nomor-Plat nomor kendaraan
harga_sewa_perhari-Harga sewa mobil per hari
tgl_sewa-Tanggal mulai sewa
tgl_kembali_rencana-Tanggal rencana kembali
total_bayar-Total biaya sewa
tgl_kembali_aktual-Tanggal pengembalian riil
denda-Denda keterlambatan jika ada

Kelemahan 1NF: Duplikasi data tinggi. Jika pelanggan melakukan rental berkali-kali, nama, nomor KTP, dan info kontak harus diinput ulang.

C. Bentuk Normal Ketiga (3NF)

Bentuk 2NF di atas sudah memenuhi kriteria 3NF. Seluruh kolom non-key bergantung langsung pada primary key masing-masing, sehingga tidak ada ketergantungan transitif.

7. Implementasi Desain Database (DDL SQL)

-- Membuat Database
CREATE DATABASE uas_rental_mobil;
USE uas_rental_mobil;

-- Tabel Pelanggan
CREATE TABLE pelanggan (
    id_pelanggan INT AUTO_INCREMENT PRIMARY KEY,
    nama VARCHAR(100) NOT NULL,
    no_ktp VARCHAR(16) NOT NULL UNIQUE,
    no_telp VARCHAR(15) NOT NULL,
    alamat TEXT NOT NULL
);

-- Tabel Mobil
CREATE TABLE mobil (
    id_mobil INT AUTO_INCREMENT PRIMARY KEY,
    merek VARCHAR(50) NOT NULL,
    model VARCHAR(50) NOT NULL,
    plat_nomor VARCHAR(15) NOT NULL UNIQUE,
    harga_sewa_perhari INT NOT NULL,
    status VARCHAR(20) DEFAULT 'Tersedia'
);

-- Tabel Transaksi Sewa
CREATE TABLE transaksi_sewa (
    id_sewa INT AUTO_INCREMENT PRIMARY KEY,
    id_pelanggan INT NOT NULL,
    id_mobil INT NOT NULL,
    tgl_sewa DATE NOT NULL,
    tgl_kembali_rencana DATE NOT NULL,
    total_bayar INT NOT NULL,
    FOREIGN KEY (id_pelanggan) REFERENCES pelanggan(id_pelanggan) ON DELETE CASCADE,
    FOREIGN KEY (id_mobil) REFERENCES mobil(id_mobil) ON DELETE CASCADE
);

-- Tabel Pengembalian
CREATE TABLE pengembalian (
    id_kembali INT AUTO_INCREMENT PRIMARY KEY,
    id_sewa INT NOT NULL UNIQUE,
    tgl_kembali_aktual DATE NOT NULL,
    denda INT DEFAULT 0,
    FOREIGN KEY (id_sewa) REFERENCES transaksi_sewa(id_sewa) ON DELETE CASCADE
);

A. Pengisian Data (Insert)

('Budi Santoso', '3201112223330006', '0812233445', 'Jl. Merdeka No. 12');

-- Mengisi Data Mobil

('Suzuki', 'Ertiga', 'B 9999 OK', 300000, 'Tersedia'),
('Toyota', 'Avanza', 'B 1234 CD', 350000, 'Tersedia');

-- Mengisi Data Transaksi Sewa

(1, 1, '2026-06-01', '2026-06-03', 600000);

B. Pembaruan Data (Update)

-- Memperbarui harga sewa mobil Suzuki Ertiga (ID: 1)
UPDATE mobil SET harga_sewa_perhari = 320000 WHERE id_mobil = 1;

-- Memperbarui alamat pelanggan Andi Wijaya (ID: 1)
UPDATE pelanggan SET alamat = 'Jl. Baru No. 99' WHERE id_pelanggan = 1;

C. Penghapusan Data (Delete)

-- Menghapus pelanggan dengan ID 3
DELETE FROM pelanggan WHERE id_pelanggan = 3;

9. Aplikasi CRUD (Tabel Master Mobil)

A. Menggunakan Python (CLI/Console)

Program interaktif berbasis terminal menggunakan library mysql-connector-python dengan implementasi query terparameterisasi:

import mysql.connector

def connect_db():
    return mysql.connector.connect(
        host="localhost", user="root", password="", database="uas_rental_mobil"
    )

def create_mobil(merek, model, plat, harga):
    db = connect_db()
    cursor = db.cursor()
    sql = "INSERT INTO mobil (merek, model, plat_nomor, harga_sewa_perhari) VALUES (%s, %s, %s, %s)"
    cursor.execute(sql, (merek, model, plat, harga))
    db.commit()
    db.close()

B. Menggunakan PHP (Web MVC App)

Aplikasi web interaktif dengan arsitektur MVC (Model-View-Controller) menggunakan prepared statements untuk keamanan maksimum.

  • Model (Mobil.php): Mengelola interaksi basis data (Prepared statements).
  • View (mobil_view.php): Desain responsive glassmorphism gelap menggunakan Tailwind CSS v4.
  • Controller (MobilController.php): Menangani routing logika data ke antarmuka web.
